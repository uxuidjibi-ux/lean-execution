# Quality Boundary

Token savings must never come from:
- skipping required verification;
- omitting material risks;
- guessing missing facts;
- ignoring authoritative sources;
- reducing safety checks;
- hiding uncertainty;
- claiming unperformed work;
- replacing necessary analysis with shortcuts;
- sacrificing output quality;
- ignoring explicit requests for detail.

Before omitting context, analysis, verification, or explanation, ask whether the omission could materially worsen correctness, conceal risk/uncertainty, weaken verification, or violate an explicit/authoritative instruction. If yes, it is necessary information.
