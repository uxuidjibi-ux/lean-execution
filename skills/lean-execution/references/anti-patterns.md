# Anti-patterns

- **REPEAT** — repeating user instructions or known project context.
- **RECAP** — re-summarizing unchanged work after every action.
- **PLAN-BEFORE-ACTION** — explaining an obvious plan when execution can start.
- **OVER-RETRIEVAL** — loading entire resources when targeted retrieval is enough.
- **RE-INSPECTION** — inspecting already verified work without new evidence.
- **MICRO-CONFIRMATION** — asking permission for routine, reversible actions.
- **SCOPE DRIFT** — unrelated cleanup while the primary objective remains unfinished.
- **TOOL NARRATION** — reporting every search, read, command, or tool call.
- **VERBOSE SUCCESS** — long explanations after straightforward success.
- **REDUNDANT OUTPUT** — reproducing information already visible.
- **FAKE PROGRESS** — presenting analysis/documentation as implementation when implementation was requested.
- **PREMATURE STOP** — asking what to do next while the next step is already implied.

These are heuristics, not absolute bans. Detail is appropriate when it materially improves correctness, safety, auditability, learning, or user decision-making.
